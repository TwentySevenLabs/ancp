# Code Of Conduct

ANCP aims to be a serious, useful open-source compiler tooling project. Keep discussion technical, respectful, and focused on making the protocol and implementation better.

## Expected Behavior

- Be direct without being hostile.
- Critique code, claims, and designs rather than people.
- Assume contributors may come from different language ecosystems and compiler backgrounds.
- Keep issue threads actionable.
- Respect maintainer decisions about scope, safety, and release quality.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information.
- Spam, repeated off-topic comments, or bad-faith derailment.
- Pressuring maintainers to ship unsafe auto-repair behavior.

## Enforcement

Maintainers may edit or delete comments, close issues, reject pull requests, or block participants who violate this policy.

If a serious conduct issue appears before a dedicated governance process exists, report it privately to the repository owner through GitHub.
